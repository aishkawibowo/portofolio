# Aishka Syakirah Wibowo — Personal Portfolio

Portfolio website showcasing professional work in Full-Stack Web Development, System Administration, Real-Time IoT Monitoring Systems, and Applied Data Science.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19, TypeScript)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animation:** [Framer Motion](https://www.framer-motion.com/) & [Lucide Icons](https://lucide.dev/)
- **Deployment:** Vercel

## Getting Started

Run the development server locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm run start
```
